# Expense Tracker — व्यय ट्रैकर 💰

A free, no-login, **client-side expense tracker** web app with a Hindi (हिंदी) UI. Track daily income and expenses, visualize spending with charts, and manage your budget — everything runs in your browser, no data leaves your device.

## ✨ Features

- **Add income & expenses** with categories, dates, and notes
- **Hindi-first UI** (हिंदी) — built for Indian users
- **Charts & analytics** — Chart.js visualizations of spending patterns
- **LocalStorage persistence** — your data stays on your device
- **Single-file app** — the whole tracker in one HTML file

## 🛠 Tech Stack

- **HTML5** + **CSS** + **vanilla JavaScript**
- **Chart.js** (CDN) for charts
- **Font Awesome** (CDN) for icons
- No build step, no backend

## 🚀 Quick Start

Open `index.html` in any browser — that's it. Or serve it:

```bash
python3 -m http.server 8000
```
